# به‌روزرسانی مرحله دوم داشبورد گذران وقت

این بسته پنج اصلاح را اعمال می‌کند:

1. فونت تیترها: `B Titr` و فونت متن: `B Nazanin`؛
2. اصلاح جهت اسلایدرهای سن، تعداد فعالیت‌ها و تعداد گروه‌ها؛
3. نمایش هم‌زمان کد فعالیت و عنوان رسمی فارسی فعالیت؛
4. حذف گزینه «مطابق کد استتا» از روش وزن‌دهی؛
5. جایگزینی عنوان `app` در منوی کناری با «نمای کلی».

## نصب به‌روزرسانی

1. داشبورد را در ترمینال با `Ctrl + C` متوقف کنید.
2. از پوشه فعلی پروژه یک نسخه پشتیبان بگیرید.
3. محتویات این بسته را داخل پوشه `timeuse_streamlit_starter` کپی کنید.
4. در صورت درخواست ویندوز، گزینه Replace/Overwrite را انتخاب کنید.

ساختار مهم پس از کپی باید به شکل زیر باشد:

```text
timeuse_streamlit_starter
├── app.py
├── dashboard_main.py
├── ui_style.py
├── prepare_daily_profile_data.py
├── pages
│   └── 2_الگوی_روزانه.py
└── data
    └── processed
        └── activity_labels.csv
```

فایل قدیمی `app.py` با یک مسیریاب جدید جایگزین می‌شود و محتوای صفحه اصلی در
`dashboard_main.py` قرار می‌گیرد.

## اجرای داشبورد

فعال‌سازی محیط مجازی الزامی نیست. از داخل پوشه پروژه اجرا کنید:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

سپس آدرس زیر را باز کنید:

```text
http://localhost:8501
```

## درباره برچسب فعالیت‌ها

فایل `activity_labels.csv` از شیت «ساختار طبقه‌بندی» فایل ICATUS ساخته شده است.
این فایل 165 عنوان سه‌رقمی دارد و تمام 164 کد فعالیت مشاهده‌شده در داده تمیزشده را پوشش می‌دهد.
برای اضافه‌شدن نام فعالیت‌ها نیازی به اجرای مجدد `prepare_data.py` نیست.

## درباره وزن‌دهی

در صفحه الگوی روزانه فقط دو گزینه باقی مانده است:

- وزن طرح (`weight_person`)
- بدون وزن

فایل پردازش‌شده قبلی همچنان قابل استفاده است. برای حذف کامل ستون قدیمی `pooled_weight`
از فایل پردازش‌شده نیز می‌توانید یک‌بار دستور زیر را اجرا کنید:

```powershell
.\.venv\Scripts\python.exe prepare_daily_profile_data.py
```

## فونت‌ها

کد از نام فونت‌های نصب‌شده در ویندوز استفاده می‌کند و فایل فونت داخل پروژه قرار نمی‌دهد.
اگر `B Titr` یا `B Nazanin` روی سیستم نصب نباشد، مرورگر به‌ترتیب از Tahoma و Arial استفاده می‌کند.
