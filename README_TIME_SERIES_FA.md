# افزونه صفحه «روند زمانی فعالیت‌ها»

این افزونه یک صفحه جدید به داشبورد گذران وقت اضافه می‌کند که با آن می‌توان روند ۱۲ دوره آمارگیری را برای یک کد یا مجموعه‌ای از کدهای فعالیت رسم کرد.

## فایل‌های افزونه

```text
app.py
pages/3_روند_زمانی_فعالیت‌ها.py
data/processed/activity_labels.csv
```

## نصب

1. اجرای داشبورد را در ترمینال با `Ctrl + C` متوقف کنید.
2. محتوای این پوشه را در ریشه پروژه `timeuse_streamlit_starter` کپی کنید.
3. هنگام سؤال ویندوز، جایگزینی `app.py` را تأیید کنید.
4. داشبورد را دوباره اجرا کنید:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

برای این افزونه نیازی به اجرای مجدد `prepare_data.py` نیست؛ صفحه جدید از فایل موجود زیر استفاده می‌کند:

```text
data/processed/timeuse_person_activity.parquet
```

یا نسخه جایگزین آن:

```text
data/processed/timeuse_person_activity.pkl.gz
```

## قابلیت‌ها

- انتخاب سال‌ها و فصل‌های آمارگیری
- فیلتر جنسیت، وضعیت اشتغال و دامنه سنی
- انتخاب وزن طرح یا محاسبه بدون وزن
- نمایش زمان برحسب ساعت یا دقیقه
- جست‌وجو و انتخاب کد فعالیت همراه با عنوان فارسی
- تجمیع چند کد به‌عنوان یک فعالیت واحد
- مقایسه جداگانه چند کد
- نمایش سه شاخص:
  - متوسط زمان در کل جامعه
  - متوسط زمان در میان مشارکت‌کنندگان
  - نرخ مشارکت
- دانلود داده پشت نمودار به فرمت CSV

## بازتولید دو مثال Stata

### امور مذهبی

کدهای زیر را انتخاب کنید و حالت تجمیعی را به کار ببرید:

```text
741، 742، 749
```

سه شاخص را هم‌زمان فعال نگه دارید.

### نزاع

فقط کد زیر را انتخاب کنید:

```text
719
```

برای نزدیک‌شدن به نمودار نمونه، تیک «متوسط زمان در کل جامعه» را بردارید و دو شاخص زیر را نگه دارید:

- متوسط زمان مشارکت‌کنندگان
- نرخ مشارکت

## تعریف شاخص‌ها

اگر `m_i` مجموع دقیقه فعالیت انتخاب‌شده برای فرد و `w_i` وزن طرح باشد:

```text
متوسط کل جامعه = مجموع(w_i × m_i) / مجموع(w_i)
نرخ مشارکت = 100 × مجموع(w_i × I[m_i>0]) / مجموع(w_i)
متوسط مشارکت‌کنندگان = مجموع(w_i × m_i) / مجموع(w_i × I[m_i>0])
```

در حالت انتخاب چند کد و «تجمیع»، ابتدا دقیقه همه کدهای انتخاب‌شده برای هر فرد جمع می‌شود و سپس شاخص‌ها محاسبه می‌شوند.
