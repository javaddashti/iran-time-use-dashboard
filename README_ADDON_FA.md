# افزودن صفحه «الگوی روزانه» به داشبورد گذران وقت

این افزونه دو فایل دارد:

- `prepare_daily_profile_data.py`
- `pages/2_الگوی_روزانه.py`

## نصب

1. فایل `prepare_daily_profile_data.py` را کنار `app.py` و `prepare_data.py` کپی کنید.
2. پوشه `pages` را کنار `app.py` کپی کنید.
3. محیط مجازی را فعال کنید.
4. فایل ویژه نمودار روزانه را بسازید:

```powershell
python prepare_daily_profile_data.py
```

5. داشبورد را دوباره اجرا کنید:

```powershell
python -m streamlit run app.py
```

در منوی صفحات Streamlit، صفحه «الگوی روزانه» ظاهر می‌شود.

## منطق محاسبه

- ۹۶ بازه ۱۵ دقیقه‌ای فعالیت اصلی نگه داشته می‌شوند.
- کدهای فعالیت به ۹ گروه broad تبدیل می‌شوند.
- صفحه داشبورد طبقه‌بندی ۸ گروهی یا ۶ گروهی را می‌سازد.
- وزن پیش‌فرض همان وزن نرمال‌شده در سطح موج است که در کد Stata استفاده شده است.
- کاربر می‌تواند تا شش گروه دلخواه بر اساس جنسیت، اشتغال، سن و نسبت با سرپرست بسازد.
